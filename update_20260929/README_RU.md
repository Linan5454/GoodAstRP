# GoodAstRP — иконки предметов и HUD перков

## Файлы для GitHub
Загрузите PNG `arena_*_v2.png` и `case_*_v2.png` из родительской папки `File for github` в корень ветки `main` репозитория Linan5454/GoodAstRP. Имена файлов сохраняйте точно: они используются в Lua.

## Установка интерфейса
Папка `addons` содержит файлы обновления двух существующих дополнений. Скопируйте её содержимое в `garrysmod/addons`, объединив папки. Перед заменой Lua сохраните старые версии. Затем перезапустите сервер и переподключите клиентов: это обновляет общую конфигурацию, HUD и клиентские материалы вместе.

Новые изображения доступны локально и через GitHub. Серверные autorun-файлы добавляют материалы в список загрузки клиентов. Уже выигранные предметы получают новые иконки по ID награды.

## Что изменено
- Для активных перков: ромбы с белыми минималистичными иконками, перекрывающая нижний угол плашка клавиш, короткое название под ней.
- Во время перезарядки: приглушённая иконка, таймер, индикатор восстановления; клавиши остаются видны.
- Для 88 наград кейсов: новые изображения по предмету или типу бонуса. Одинаковые предметы используют одну иллюстрацию.
- Старые иконки для пассивных перков не заменены; редизайн относится к показанной на скриншоте нижней панели активных способностей.

## Проверка
`preview.html` — автономный макет HUD и галерея предметов. Кнопка переключает готовность и перезарядку. `preview_hud_ready.png` и `preview_hud_cooldown.png` — изображения макета, не скриншоты игры.
Синтаксис Lua проверяется `validate_package.py` (стандартный парсер, GLua `continue` заменяется только в памяти при проверке). Проверка внутри Garry’s Mod нужна отдельно.

## Генерация
Изображения созданы с нуля встроенным генератором ImageGen. Промпты и исходные пути сохранены в `generation_prompts.json` и `case_generation_prompts.jsonl`. `reward_manifest.json` связывает каждую награду с новым PNG.
