# Иконки Onyx Phone
Созданы 23 сентября 2026 года встроенным генератором изображений. 10 PNG, каждый 1254×1254, RGBA с прозрачными углами. Исходные файлы проекта не перезаписаны.

Загрузите в GitHub файлы `onyx-ios-*.png`, затем передайте ссылки. Подойдут прямые raw-ссылки или ссылки GitHub с /blob/: загрузчик умеет преобразовывать их в raw.

| Приложение | Ключ | Файл |
|---|---|---|
| Телефон | call | onyx-ios-call.png |
| Сообщения | messenger | onyx-ios-messenger.png |
| GoodBank | bank | onyx-ios-bank.png |
| Настройки | settings | onyx-ios-settings.png |
| Заметки | notes | onyx-ios-notes.png |
| GPS | gps | onyx-ios-gps.png |
| Камера | camera | onyx-ios-camera.png |
| Службы 911 | services | onyx-ios-services.png |
| Darknet | darknet | onyx-ios-darknet.png |
| Увольнение | demote | onyx-ios-demote.png |

В аддоне подготовлен `Onyx.Phone.Config.AppIconURLs`. Ссылки пока оставлены пустыми, поэтому сейчас используются встроенные иконки. После добавления ссылок загруженная PNG заменяет встроенную; ожидание, ошибка HTTP, неверный формат или тайм-аут сохраняют встроенный вариант. Успешные картинки кэшируются на клиенте, при ошибке предусмотрена повторная попытка.

Проектные обои возвращены в «Настройки → Обои → GoodAstRP · проект» (шестой пункт коллекции). Существующие пять цветовых вариантов и пользовательская ссылка сохранены.

Запросы, использованные для генерации, находятся в `onyx-ios-prompts.md`.
